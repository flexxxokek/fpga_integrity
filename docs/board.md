## 2. Тактирование и сброс

| Поле | Значение |
|------|----------|
| Частота бортового генератора | 50 МГц (`CLOCK_50`, PIN_Y2, 3.3-V LVTTL) |
| Пин clock | PIN_Y2 |
| Нужен ли PLL/MMCM | нет — тактовая сеть делится на 4 счётчиком в board-топе |
| Целевая частота стенда | **12.5 МГц** (80.000 нс) = `CLOCK_50 / 4`, `CLK_FREQ_HZ=12_500_000` |

| Кнопка сброса (пин, полярность) | `KEY[0]` = PIN_M23, активный **низкий**; в RTL инвертируется |

Прямая работа на 50 МГц невозможна: TimeQuest даёт Fmax 19.84 МГц на slow
85C-модели для полного стенда (6 lane + SHA-256 + UART). Делитель на 4 даёт
запас по таймингу (worst slack +19.14 нс) без перепроектирования критического
пути. Fmax и утилизация из Quartus — в
[docs/results/board.md](results/board.md).

## 3. Интерфейс с хостом

| Поле | Значение |
|------|----------|
| UART / USB-UART мост | RS-232 через transceiver на плате (DB9), 3.3-V LVTTL на стороне FPGA |
| Пины txd / rxd | `UART_TXD` = PIN_G9, `UART_RXD` = PIN_G12 |
| Скорость по умолчанию | 115 200 бод, 8N1 |
| Альтернативы (USB, Ethernet) | USB-Blaster используется только для JTAG; Ethernet на стенде не задействован |

UART_RXD подтянут вверх в `.qsf`: `report_uart` использует его как признак
свободной линии хоста (`done && uart_rxd`).

**Перезапуск кампании.** `KEY[0]` (PIN_M23) вызывает короткий reset-импульс
(~26 мс) по фронту нажатия, после чего кампания и UART-отчёт повторяются.
Тактовый делитель `CLOCK_50 / 4` при этом **не сбрасывается**: `report_uart`
должен продолжать тактироваться во время reset, иначе его `start_q` не очищается
и следующий отчёт не отправляется.

**Визуализация без хоста.** `KEY[1]` (PIN_M21) переключает отображаемый lane
(0…5, с антидребезгом 20 мс). На HEX7 виден номер lane, на HEX6…HEX4 — число
обработанных пакетов в hex (счётчик обновляется во время кампании), на
HEX3…HEX0 — число обработанных байтов в hex. Зелёные LEDG[5:0] загораются для
lane, у которых `missed == 0`, LEDG[8] дублирует `done`. Красные LEDR[0..2]
показывают heartbeat/busy/done.

## 4. Отладка

| Поле | Значение |
|------|----------|
| LED (пины) | `LEDR[0]` PIN_G19 (heartbeat), `LEDR[1]` PIN_F19 (busy), `LEDR[2]` PIN_E19 (done); `LEDG[5:0]` — «успех» по каждому lane; `LEDG[8]` — общий done |
| Семисегментные индикаторы | `HEX[7]` PIN_AD17… (выбранный lane), `HEX[6:4]` — пакеты в hex (live), `HEX[3:0]` — байты в hex (live) |
| Кнопки / переключатели | `KEY[0]` PIN_M23 — сброс/перезапуск; KEY[1..3] зарезервированы |
| Программатор / способ прошивки | USB-Blaster (JTAG), `quartus_pgm -m JTAG -o "p;output_files/de2_115.sof@1"` |
